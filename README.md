## Apa yang Sudah Saya Pelajari di Modul

1. Saya jadi paham kalau Scaffold itu kerangka dasar sebuah halaman di Flutter. Jadi MaterialApp itu yang mengatur aplikasinya secara keseluruhan, terus di dalamnya ada Scaffold yang nyediain tempat-tempatnya: AppBar di atas, body di tengah, drawer dari samping, bottomNavigationBar di bawah, sama floatingActionButton buat aksi utama.

2. Saya belajar cara pakai bagian-bagian itu sekaligus nyambungin tombol ke function. Misalnya tombol Profil di AppBar, menu di drawer, sama bottom navigation dipakai buat pindah halaman, terus tombol tambah dipakai buat nampilin SnackBar. Jadi tombolnya benar-benar jalan, bukan cuma pajangan.

3. Saya belajar nyusun tampilan pakai widget dasar kayak Text, Icon, Container, Row, Column, dan Center, terus kodenya dipisah-pisah biar rapi. Halaman Beranda dan Profil dibuat file-nya sendiri-sendiri, dan data nama, NIM, sama email cuma ditulis sekali di satu tempat, jadi kalau mau diubah tidak perlu ubah di banyak file.

## Tentang Aplikasi Ini

Aplikasi Portal Mahasiswa ini ada halaman Beranda yang menampilkan tulisan Selamat Datang di tengah, dan halaman Profil yang menampilkan ikon orang, nama, NIM, dan email di tengah. Navigasinya bisa lewat tombol Profil di AppBar, menu drawer, atau bottom navigation.

## Cara Menjalankan

1. Masuk ke folder project ini.
2. Jalankan `flutter pub get`, lalu `flutter run`.
